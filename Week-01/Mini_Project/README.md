## 🎯 Objective
To build and evaluate a regression model that predicts house prices using a given dataset, 
as part of hands-on practice for the Machine Learning Specialization.

## 🛠️ Tools & Libraries
- Python
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-learn

## 📊 Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Feature engineering
4. Model training (Linear Regression / other regression models)
5. Model evaluation (MSE, R² score, etc.)
6. Visualization of results

## 📈 Results
Model outputs, plots, and evaluation metrics are saved in the `results/` folder.
