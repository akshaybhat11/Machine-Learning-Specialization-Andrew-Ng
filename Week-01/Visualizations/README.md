# Visualizations — Week 1

This folder contains 3 core visualizations from Week 1, generated using **Python + Matplotlib**.

| File | Description |
|---|---|
| `01_Linear_Regression.png` | Shows a set of training data points along with the best-fit regression line, illustrating how linear regression models the relationship between input (x) and output (y). |
| `02_Cost_Function.png` | Shows the U/bowl-shaped cost function J(w), with the minimum cost point marked — illustrating the goal of minimizing cost during training. |
| `03_Gradient_Descent.png` | Shows the step-by-step path gradient descent takes on the cost curve, moving downhill from a starting point toward the minimum. |

### Notes
- Each graph focuses on a single concept.
- Axes are labeled and important points (e.g., minimum cost) are marked.
- Graphs were generated directly from code (not screenshots) and exported as PNG for easy viewing on GitHub.
